How does it play?

TabPFN uses past moves to answer one question: which turn looks best from here?

  1. Start with random moves

    We record 1,000 moves: the board, the turn, and what happened next. Every move earns a reward.

    +1 Eat an apple−1 Crash or starve−0.01 Any other move

  2. Put each move in a row

    Each possible turn is described by a few numbers: does it crash, does it eat the apple, does it get closer, how much room is left. The Features tab shows them.

    Move featuresTurn leftReward −0.01

  3. Learn from the rewards

    We give TabPFN the rows and their rewards. It uses those examples to predict how other moves might turn out.

  4. Include what comes next

    A safe move can still lead to a dead end. After the first fit, we update the targets with the best predicted return from the next board.

    TargetWhat we fit to=Reward nowWhat happened+0.95 × next returnBest predicted next turn

    When the game ends, there is no next return to add. Repeating this is called fitted Q iteration.

  5. Choose a turn

    TabPFN scores left, straight, and right in one request. The snake takes the highest score, even if that move would crash.

  6. Save the result

    The new move joins the table. We periodically refit with the extra rows so later predictions can use them.

TabPFN’s weights stay fixed. What changes is the table of examples and the targets we ask it to predict.

A feature is one number describing a possible move. TabPFN never sees the grid itself. Try a turn below to see which numbers change.
